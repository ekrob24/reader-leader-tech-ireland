Agentic workflow / Reader Leader

The agent earns trust by knowing when not to speak.

A production-shaped operating model for an accent-aware reading-record platform. The workflow separates evidence, context, judgement, child feedback, teacher briefing, content governance, and evaluation so every role has one responsibility and every handoff is inspectable.

8 roles

Six bounded AI/data agents, one deterministic policy gate, and one human reviewer loop. The model proposes; the policy validates; the adult decides what the record means.

BMAD as the build discipline.

BMAD is used for the product-development lifecycle, not copied into the child runtime. It keeps intent, architecture, stories, implementation, review, and learning explicit.

Framework decision

OpenAI Agents SDK + Trigger.dev

Use the Agents SDK for typed tools, handoffs, guardrails, sessions, and traces. Use Trigger.dev for durable, retryable, asynchronous execution. Keep the final action policy deterministic in TypeScript outside the model.

Handoff contracts, not vibes.

The handoff is an event with a schema, an idempotency key, a trace ID, and an owner. If a downstream agent cannot validate its input, it escalates rather than improvises.

1. Content approved

Content Steward Agent → Session Orchestrator. Payload: immutable passage version, phonics profile, pronunciation set, rights/safety status, audience scope.

2. Evidence bundle ready

Evidence Analyst → Judgement Agent. Payload: token-level timings, event candidates, confidence vector, audio quality, provider/version, and evidence references.

3. Action proposed

Judgement Agent → Policy Gate. Payload: one action enum, reason code, confidence, evidence refs, teacher note, and trace ID.

4. Action validated

Policy Gate → Child Feedback Agent + Teacher Briefing Agent. Payload: safe action, approved template key, adult-only reason, and escalation state.

5. Review returned

Teacher/SET → Evaluation Runner. Payload: accepted/overridden decision, reason, speaker group, and optional adjudication note. Original output remains immutable.
